Leapfrog is a multistate population projection model for demographic and HIV
epidemic estimation with interfaces in R, Python, C++ and Delphi.

It's has 2 main goals:
* Be a publicly available version of the Spectrum model end-users can interact
   with
* Be modular and extensibe to avoid code duplication

Historically the core HIV epidemic model would be re-implemented for various
application e.g. Shiny90 for assessing 90-90-90 targets, EPP for fitting
incidence, CSAVR etc. Leapfrog should be a single implementation we can use
anywhere.

[Project on GitHub](https://github.com/hivtools/leapfrog)
